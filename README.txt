  ---
  🌐 API 层的作用

  API 层基于 FastAPI 构建，端口 8089，主要提供 HTTP REST 接口，作用如下：

  1. 对外暴露 HTTP 访问入口

  与 websocket_client.py 的实时长连接不同，API 层提供的是标准的 请求-响应式 HTTP 接口，适合：
  - Web 前端调用
  - 第三方系统集成
  - 运维监控探活

  2. 具体路由与功能

  ┌────────────────────────────────────┬────────┬───────────────────────────────────┬──────────────────────────────────┐
  │                路由                │  方法  │               功能                │             当前状态             │
  ├────────────────────────────────────┼────────┼───────────────────────────────────┼──────────────────────────────────┤
  │ /api/v1/health                     │ GET    │ 健康检查 — 判断服务是否存活       │ ✅ 可用                          │
  ├────────────────────────────────────┼────────┼───────────────────────────────────┼──────────────────────────────────┤
  │ /api/v1/ready                      │ GET    │ 就绪检查 — 判断服务是否可接受请求 │ ⚠️  TODO：需接入实际依赖检查      │
  ├────────────────────────────────────┼────────┼───────────────────────────────────┼──────────────────────────────────┤
  │ /api/v1/chat/message               │ POST   │ 发送消息给 Agent 处理             │ ⚠️  TODO：返回 mock，未接入 Agent │
  ├────────────────────────────────────┼────────┼───────────────────────────────────┼──────────────────────────────────┤
  │ /api/v1/chat/sessions/{id}/history │ GET    │ 获取会话历史消息                  │ ⚠️  TODO：返回空                  │
  ├────────────────────────────────────┼────────┼───────────────────────────────────┼──────────────────────────────────┤
  │ /api/v1/chat/sessions/{id}         │ DELETE │ 清除指定会话                      │ ⚠️  TODO：占位响应                │
  └────────────────────────────────────┴────────┴───────────────────────────────────┴──────────────────────────────────┘

  3. 附加能力

  - Swagger 文档：访问 /docs 自动生成 API 文档
  - ReDoc 文档：访问 /redoc 生成另一种风格文档
  - CORS 全开：allow_origins=["*"]，允许任何前端跨域调用
  - 生命周期管理：通过 lifespan 上下文管理器控制启动/关闭时的资源初始化和清理

  ---
  ⚠️  当前关键问题

  API 层与核心引擎是断开的。chat.py 的消息处理端点返回的是模拟数据，没有调用 Agent.run()。项目的两条通信通道现状：

  ┌─────────────────────┬──────────────────┬───────────────────────────────────────────────┐
  │        通道         │       方式       │                是否连通 Agent                 │
  ├─────────────────────┼──────────────────┼───────────────────────────────────────────────┤
  │ websocket_client.py │ WebSocket 长连接 │ ✅ 已连通 — 新消息会调用 process_with_agent() │
  ├─────────────────────┼──────────────────┼───────────────────────────────────────────────┤
  │ api/routes/chat.py  │ HTTP REST        │ ❌ 未连通 — 返回 mock 响应                    │
  └─────────────────────┴──────────────────┴───────────────────────────────────────────────┘

  简单说，API 层目前是个空壳，路由都定义好了，但核心的聊天功能还没接上 Agent 引擎。
